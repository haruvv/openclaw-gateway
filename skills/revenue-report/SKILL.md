# Revenue Report

月次で収益・アクセス状況をまとめ、haruvv に報告する。
調査・送信は L1（承認不要）。

## When to use

- PENDING_TASKS.txt に "revenue-report" が書かれているとき
- haruvv から「収益どう？」「レポート見せて」と聞かれたとき

---

## 前提条件チェック

`~/clawd/MEMORY.md` を読み、公開済みサイトの情報を確認する:
- サイト URL
- リポジトリ名
- アフィリエイトプログラム名（Amazonアソシエイト・もしもアフィリエイト等）
- 公開日

**公開済みサイトがない場合**: 「まだ公開サイトがありません。」と Telegram に送信して終了。

---

## Step 1: アクセス数を確認

### Cloudflare Analytics（メイン）

Cloudflare Pages のアナリティクス API から過去30日の PV を取得する。

```bash
# Cloudflare Analytics API
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/analytics/..." \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

API が使えない場合: WebFetch でサイトのトップページにアクセスし、表示を確認（死活確認のみ）。

---

## Step 2: 収益を確認

### 確認できるもの（優先順）

1. **Amazonアソシエイト**: WebFetch でダッシュボード URL にアクセス（要ログイン → 取得不可の場合はスキップ）
2. **もしもアフィリエイト**: 同上
3. **確認できない場合**: haruvv に「アソシエイトダッシュボードで確認してください」と案内する

収益データが取得できない場合でも、アクセス数だけでレポートを送る。

---

## Step 3: Telegram に送信（L1 — 承認不要）

```
📊 月次収益レポート (<年月>)

━━━━━━━━━━━━━━━━
🌐 <サイト名>
URL: <URL>
公開: <公開からX日>

📈 アクセス（過去30日）
PV: X件
ユニーク訪問: X件

💰 収益（過去30日）
<アフィリエイト名>: X円（取得できない場合は「ダッシュボードで確認」）

📝 公開記事数: X件
━━━━━━━━━━━━━━━━

<サイトが複数ある場合は繰り返す>

次のアクション:
- 記事追加が必要なサイト: <サイト名>（最終更新: X日前）
- 「記事書いて」と返信すると content-create が実行されます
```

---

## Step 4: MEMORY.md を更新

レポート送信後、以下を MEMORY.md に記録する:

```
## Revenue Report - <年月>

- <サイト名>: PV X件、収益 X円（<日付>）
```

---

## 注意事項

- **取得できないデータは正直に**: 「確認できませんでした」と書く。推測値を書かない
- **毎月1回**: 同月内に2回送らない（MEMORY.md の最終レポート日時を確認）
- **アクセスできないダッシュボードは無理に取得しない**: ログインが必要なページはスキップする
