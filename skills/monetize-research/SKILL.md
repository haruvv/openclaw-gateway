# Monetize Research

収益化に適したニッチを自律的に調査・評価し、**1件に絞った実行推薦**を haruvv に送信する。
調査・提案は L1（承認不要）。実装着手は L3（必ず承認を取る）。

## When to use

- PENDING_TASKS.txt に "monetize-research" が書かれているとき
- haruvv から「収益化アイデアを調べて」と依頼されたとき

---

## Step 1: トレンド調査（L1 — 承認不要）

WebSearch で以下を調べる:

```
- 今月の日本語アフィリエイト高単価ジャンル 2026
- 競合が少ない特化ブログのニッチ 2026
- 日本語 micro saas 個人開発 収益 2026
- Amazonアソシエイト 高報酬カテゴリ 最新
- note 有料マガジン 売れている テーマ
```

---

## Step 2: 評価・1件に絞る

候補を以下の基準で評価し、**最もスコアが高い1件だけ**を選ぶ。

| 評価軸 | 理想 |
|---|---|
| 収益ポテンシャル | アフィリエイト単価高 / SaaS 月額課金 |
| 競合の少なさ | 1ページ目に弱いドメインが多い |
| OpenClaw による自動化適性 | 記事自動生成 / 定期更新が可能 |
| 初期コスト | ゼロ〜低コスト |
| 継続性 | 半年以上続けられる市場 |

迷ったら「OpenClaw が記事を量産できるか」を最優先にする。

---

以下のフォーマットで送信する:

```
💡 収益化リサーチ完了

━━━━━━━━━━━━━━━━
ニッチ: <名前>
カテゴリ: <アフィリエイト / SaaS / コンテンツ販売>
想定収益: 月 X〜Y 万円

なぜこれを選んだか:
<競合状況・単価・自動化適性を踏まえた理由を3行以内で>

必要な作業:
- <作業1>
- <作業2>
- <作業3>

リスク: <最大の懸念点を1行>
━━━━━━━━━━━━━━━━

進めてよいですか？「はい」で次のステップ（サイト設計）に着手します。
```

---

## Step 4: 承認を受けたとき（L3 — 承認後に実行）

haruvv が「はい」「進めて」「OK」などで応答したら:

1. **サイト設計案を作成する**（L2: 作成して Telegram に送信）
   - サイト名・ドメイン候補
   - 技術スタック（Astro + Cloudflare Pages を推奨）
   - トップページ構成
   - 最初に書く記事5件のタイトル案

2. **「このまま実装しますか？」と確認**（L3: 承認必要）

3. **承認を得たら `dev-team` スキルで GitHub Issue を起票**

### Issue 起票テンプレート

```
タイトル: [収益化] <ニッチ名> アフィリエイトサイト構築

## 概要
<ニッチ名> をターゲットにしたアフィリエイトサイトを構築・デプロイする。

## 技術スタック
- フレームワーク: Astro（静的生成）
- ホスティング: Cloudflare Pages
- コンテンツ管理: Markdown（Git 管理）

## 要件
- トップページ（サイト概要・人気記事一覧）
- 記事ページ（Markdown からレンダリング）
- アフィリエイトリンク挿入可能な構造
- SEO 基本設定（メタタグ・OGP・sitemap.xml）
- サンプル記事5件（各1000字以上）

## 完成基準
- `npx wrangler pages deploy` でデプロイ成功
- トップページ・記事ページが表示される
- デプロイ URL を Issue にコメント

## ラベル
ai-dev
```

---

## 注意事項

- **調査は1回で完結させる**: 「あとで調べ直す」はしない。今ある情報で判断して送信する
- **L3 は必ず承認を取る**: デプロイ・外部サービス登録は haruvv の yes なしに実行しない
- **コストが発生するものは事前確認**: ドメイン取得・有料 API は必ず報告してから進む
- **1ニッチに集中**: 複数候補を並べて選ばせない。自分で選んで1件を推薦する
